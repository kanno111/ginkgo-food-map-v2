# Ginkgo 美食地图功能说明

## 这是什么系统

Ginkgo 美食地图是一个面向电子科技大学学生的校园美食平台。系统最终会帮助学生查找校园及周边餐厅、查看他人的真实评价，并分享自己的用餐体验。

当前项目仍处于重构开发阶段。下面将“已经可以使用”和“还在开发”的功能分开列出，避免把计划中的功能误认为已经完成。

## 当前已经可以使用

### 查看系统连接状态

打开前端首页后，页面会自动检查前端能否连接到后端，并显示连接正常或暂未连接。这个功能主要用于开发和部署时快速判断系统是否成功启动。

### 获取注册邮箱验证码

用户可以申请注册验证码，但邮箱必须属于系统允许的电子科技大学学生邮箱域名。当前默认只允许以 `@std.uestc.edu.cn` 结尾的邮箱，并且会精确检查域名，不能用相似域名冒充。

为了防止验证码被滥用：

- 验证码是 6 位数字，5 分钟后失效。
- 同一个邮箱 60 秒内不能重复发送。
- 同一个邮箱在一小时和一天内都有发送次数上限。
- 连续输错次数达到上限后，当前验证码会失效。
- 验证码成功使用后立即失效，不能再次使用。
- 系统只保存验证码的校验结果，不直接保存用户收到的明文验证码。

如果邮箱已经注册，系统不会再次发送注册验证码。

### 使用校园邮箱注册账号

用户可以提交校园邮箱、收到的验证码、用户名和密码创建账号。系统会再次检查邮箱、验证码、用户名和密码，不能只靠前端页面的提示绕过规则。

目前注册后端接口和前端注册页面都已经完成。用户可以从首页或顶部导航进入注册页，填写学生邮箱并发送验证码，然后填写验证码、用户名、密码和确认密码完成注册。页面会提示输入问题、接口错误和注册结果，并在验证码发送成功后显示60秒重新发送倒计时。

- 邮箱必须属于允许的校园邮箱域名，当前默认为 `@std.uestc.edu.cn`。
- 用户名必须是 3 至 32 个文字、数字或下划线，并且不能与现有用户重复。
- 密码至少 8 个字符，并且至少包含字母或中文等文字以及数字。
- 密码不会以原文保存，数据库中只保存无法直接还原的安全哈希。
- 每个邮箱和用户名只能注册一个账号，即使多人同时提交也会由数据库阻止重复数据。
- 注册验证码只能成功使用一次，注册验证码不能用于密码重置。

注册成功后系统不会自动登录，也不会直接返回登录凭证。用户可以点击成功提示中的“前往登录”，使用用户名和密码登录。

本地联调所需的账号存储空间已初始化，可以开始从注册页面测试创建账号。系统不会预先创建用户或管理员账号。

### 获取密码重置验证码

已经注册的用户可以通过绑定的校园邮箱申请密码重置验证码。为了避免别人利用接口查询某个邮箱是否注册，无论邮箱是否存在，页面都应显示相同的受理结果。

> 注意：目前只完成了验证码发送能力，使用验证码设置新密码的功能还在开发中。

### 用户名和密码登录

用户可以从顶部导航或首页进入登录页，填写注册时的用户名和密码。登录成功后返回首页，导航显示当前用户名。

- 登录使用用户名，不使用校园邮箱；密码中的空格会保留，不能随意增减。
- 当前标签页刷新后会重新向服务端确认登录状态。当前配置的登录有效期为7天，过期后需要重新登录。
- 登录凭证保存在当前标签页的临时存储中；关闭标签页后不会由系统自动恢复。浏览器自身的标签页恢复或复制功能可能保留该存储，因此在公共电脑上仍应主动退出。
- 不同设备或独立登录分别拥有各自的会话，退出一个会话不会退出其他会话。
- 用户名不存在、密码错误或账号不可用时，显示相同的登录失败提示。
- 默认15分钟内累计输错5次会临时限制该账号登录，锁定15分钟后可以重试。
- 登录服务暂时不可用时不会放行请求；临时故障保留本地凭证，方便恢复后重试。

### 退出当前登录

已登录用户可以点击顶部导航的“退出”。服务端确认退出后，当前会话立即失效，即使此前的登录凭证尚未自然过期也不能继续使用。

如果服务端暂时无法完成退出，页面会显示失败提示并保留登录状态，用户可以重试。若当前凭证已经失效，页面会清除本地登录状态。

### 更新后自动检查并发布

开发者将更新推送到 develop 后，系统检查前后端，全部通过后由服务器主动下载已检查的新版本并更新。检查失败会保留线上版本，发布后的启动检查失败会尝试恢复上一版程序。自动更新无需对 GitHub 开放服务器的 SSH 访问。

项目使用独立仓库，develop 为默认分支。首次自动检查和服务器发布已成功，可在 `http://8.137.98.235` 使用网站，并在新仓库的 Actions 页面查看每次检查与发布结果。操作说明见[自动部署文档](deployment.md)。

## 正在开发

### 多设备会话管理

当前支持各次登录分别保持会话和退出当前会话；查看设备列表、主动退出其他设备的管理页面及接口尚未完成。

### 找回密码

计划支持通过已绑定校园邮箱的验证码设置新密码。密码修改成功后，所有设备上的旧登录状态都会失效。

## 尚未迁移的主要业务

以下功能属于产品目标，目前还不能在 V2 中正式使用：

- 浏览校园及周边餐厅和美食地图。
- 查看餐厅详情、评分和其他用户的评价。
- 发布、修改和删除自己的评价。
- 收藏餐厅或建立个人美食清单。
- 上传餐厅或评价图片。
- 管理员审核内容和处理违规信息。

开发者联调所需的请求参数、响应格式、认证方式和错误码统一维护在[接口文档](api.md)，功能说明和接口文档应随实现同步更新。
