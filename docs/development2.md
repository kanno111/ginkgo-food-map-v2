## 2026-10-28：补齐密码重置后端接口

### 范围与设计

- 从干净的 develop（`5189f27`）新建 `feat/password-reset-api`，本步骤只完成验证码设置新密码的后端接口，按最小修改步骤交付审核。
- 新增公开 `POST /auth/password-reset`，接收校园邮箱、6位专用验证码和新密码；复用现有校园邮箱及密码规则，不自动登录、不返回凭证。
- 先校验输入，再消费密码重置用途验证码，最后查询账号并计算 BCrypt。只允许邮箱已验证且状态为 ACTIVE 的已有账号重置，不恢复停用、锁定或删除账号。
- MySQL 邮箱索引使用重音不敏感排序规则；重置时额外精确比较规范化后的绑定邮箱，防止另一个相似邮箱的验证码命中账号。
- 自定义条件更新在同一 SQL 中替换密码哈希并递增凭证版本、行版本，同时核对读取时的邮箱、版本与账号可用状态，防止并发覆盖。沿用认证链的最新凭证版本检查，使所有旧登录凭证失效；Redis旧会话按原TTL清理，不跨模块访问会话Mapper或存储。
- Redis验证码消费不能参与MySQL本地事务；消费后数据库故障或并发冲突须重新申请验证码，不恢复已消费凭证。新增稳定的改密冲突、服务不可用错误码，不输出底层SQL或敏感参数。
- 保留既有登录失败临时锁定，重置不会自动清除限流。未修改已执行的Flyway迁移、生产配置或发布工作流；同步更新功能说明和接口文档。

## 2026-10-28：默认保留登录并接通找回密码页面

### 范围与实现

- 在独立 `feat/persistent-login-password-reset` 分支承接上一步尚未提交的密码重置后端，完成用户要求的默认保留JWT和找回密码前端；不增加“记住我”选项，不保存账号密码。
- 沿用Bearer请求头认证，将JWT改存同源 `localStorage`，关闭页面或浏览器后可恢复；启动时仍通过 `/auth/me` 校验身份。默认7天有效期不变，不新增刷新令牌或滑动续期；存储受限时退化为本页面内存会话。
- 当前标签页的旧 `sessionStorage` 凭证会迁移并清除旧副本；持久存储已有凭证时优先使用持久凭证。跨标签页同步登录、切换账号与退出，任何凭证变化均先移除旧身份；旧401或迟到的恢复/退出响应不能覆盖其他标签页的新登录。
- 登录页新增“忘记密码”入口与 `/password-reset` 页面，支持校园邮箱发码、按截止时间计算的60秒倒计时、6位验证码、新密码及确认密码、加载防重入、失败提示和成功后返回登录。
- 发码受理提示不透露邮箱是否已注册。密码重置与发码均不附带旧Bearer凭证，防止过期令牌阻止找回密码。密码仅保留在表单中，提交完成或离开页面后清除，不进入全局Store或浏览器存储。
- 重置成功清理请求开始时的旧本地凭证，并同步同浏览器标签页；同时保留请求期间产生的新登录。其他设备的旧凭证由后端最新凭证版本校验拒绝。
- 同步更新功能、接口与前端说明。当前 `localStorage` 仍可被同源脚本读取；HTTPS与HttpOnly Cookie迁移留在后续部署和认证强化范围。
